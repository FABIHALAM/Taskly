1. Executive Summary

The MEPCO Portal is a dynamic, high-performance IT and Grid Operations Management System customized specifically for the Multan Electric Power Company (MEPCO). Designed as an enterprise solution, it streamlines Scrum sprint management, drag-and-drop Kanban task boards, real-world grid telemetry status logging, and role-based user management for sub-divisional IT engineers.

2. System Prerequisites

To run the MEPCO Portal locally, ensure the following software is installed on the hosting computer:

  • Node.js (v18.x or above)
  • MongoDB (Local MongoDB Compass instance or MongoDB Atlas cloud cluster)
  • NPM (Node Package Manager - comes bundled with Node.js)

3. Project Repository Structure

The codebase is modularly separated into two main directories:

  • client/: React frontend application styled using premium Vanilla CSS and Vite compiler.
  • server/: Express and Mongoose backend server representing REST APIs and Swagger documentation.

4. Local Machine Installation & Setup

Follow these step-by-step instructions to run the application locally:

Step A: Environment Configuration

1. Open the server/ folder. Copy .env.example and rename it to .env. Update the following values:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/mepco
JWT_SECRET=mepco_jwt_encryption_secret_key_2026

2. Open the client/ folder. Copy .env.example and rename it to .env:

VITE_API_URL=http://localhost:5000/api

Step B: Install Dependencies & Run Database Seed

Open your command line/terminal, switch to the project folder, and run the following setup commands:

# 1. Install Server Dependencies & Seed MEPCO data
cd server
npm install
npm run seed

# 2. Install Client Dependencies
cd ../client
npm install
Note on Seeding: The npm run seed command wipes any local collection and dynamically generates official MEPCO test records: active grid telemetry boards, billing projects, and subdivisional employee roles.

Step C: Start Local Servers

Launch the application using two separate terminal windows:

# Run in Server terminal
cd server
npm run dev

# Run in Client terminal
cd client
npm run dev

Access the portal in your browser at: http://localhost:5173

5. Cloud Production Deployment

The system is verified and hosted live in production environment using Vercel serverless functions:

Backend (API Server on Vercel Node Runtime)

  • Deploy Platform: Vercel (imported using server as root directory)
  • Serverless Routing: Handled dynamically via root server/vercel.json config.
  • Production Live API Endpoint: https://taskly-three-cyan.vercel.app/api

Frontend (React Client on Vercel Edge Network)

  • Deploy Platform: Vercel (imported using client as root directory)
  • Single Page Application Rewrites: Configured in client/vercel.json to prevent 404 routing errors on page refresh.
  • Production Live App URL: https://taskly-c9re.vercel.app/login
