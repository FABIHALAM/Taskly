1. Executive Summary

The MEPCO Portal Workspace is a customized, state-of-the-art enterprise resource planning and operations control system developed for the Multan Electric Power Company (MEPCO). The portal streamlines the tracking of critical sub-divisional IT grid telemetry updates, NEPRA billing integration schedules, and Scrum Sprint milestones. Featuring role-based access control, the system organizes permissions between Super Admins, Project Managers, and Subdivisional Engineers to ensure high accountability and data integrity.

2. System Architecture & Features

The system represents a classic MERN Stack (MongoDB, Express, React, Node.js) architecture configured for containerized deployment:

  • Interactive Grid Dashboard: High-end, real-time interface tracking task completions, telemetry log updates, and system metrics.
  • Role-Based Dashboards: Automated view routing for Administrators (User management, geolocation auditing) and Members (Kanban boards).
  • Gmail Telemetry Engine: Background Nodemailer transporter that dispatches secure welcome credentials and task assignments in real-time.
  • Responsive Branding: Fully styled with the official MEPCO insignia, theme, and color systems designed for corporate evaluation.

4. Local Machine Setup & Installation

To run the application locally on a host computer, follow the instructions below:

Prerequisites

Ensure the following software packages are installed:

  1. Node.js (v18.0.0 or higher)
  2. MongoDB Compass (running locally at port 27017)

Step A: Setup Environment Configurations

Configure local keys by duplicating the example blueprints:

1. In the server/ subdirectory, copy .env.example to .env and customize the settings:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/mepco
JWT_SECRET=mepco_jwt_encryption_secret_key_2026

2. In the client/ subdirectory, copy .env.example to .env:

VITE_API_URL=http://localhost:5000/api

Step B: Install Dependencies & Run Database Seed

Execute the installation commands from your command terminal:

# 1. Access the server directory, install components, and seed database
cd server
npm install
npm run seed

# 2. Access the client directory and install libraries
cd ../client
npm install
Database Seeding
Running npm run seed drops local mock collections and populates the database with real-world MEPCO IT division users, Scrum projects, and operational task lists.

Step C: Launch Local Servers

Open two separate terminal instances to run both processes concurrently:

# Run inside server terminal
cd server
npm run dev

# Run inside client terminal
cd client
npm run dev

Once started, access the local system at: http://localhost:5173

5. Docker Container Deployment

The repository features custom Docker configurations. To build and run the entire stack (React, Node, MongoDB) inside isolated containers, execute the following command from the project root folder:

docker-compose up --build
