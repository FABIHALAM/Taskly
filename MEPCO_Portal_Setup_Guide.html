1. Executive Summary

The MEPCO Portal is a dynamic, high-performance web application designed and built specifically for the Multan Electric Power Company (MEPCO) during the internship program. The system provides sub-divisional IT engineers, project managers, and administrators with an integrated environment for task management, Scrum sprints planning, and live grid operations telemetry status logging.

3. Local Machine Setup & Installation

To run the complete application package on your local computer, follow these instructions:

Prerequisites

Ensure your system has the following installed:

  • Node.js (v18.x or above)
  • MongoDB (Local MongoDB Compass instance running at 127.0.0.1:27017)

Step 1: Configure Environment Settings

Create the local environment files within the project subfolders:

1. In the server/ folder, copy .env.example and rename it to .env. Populate the settings as follows:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/mepco
JWT_SECRET=mepco_jwt_encryption_secret_key_2026

2. In the client/ folder, copy .env.example and rename it to .env:

VITE_API_URL=http://localhost:5000/api

Step 2: Install Dependencies & Run Database Seed

Run the installer steps inside both subdirectories to install required packages and populate default database values:

# Setup Server and Seed Database
cd server
npm install
npm run seed

# Setup Client
cd ../client
npm install
Seeding Database: Running npm run seed creates default user profiles, grid operations telemetry logs, and billing integration tasks directly inside your local MongoDB.

Step 3: Run the Services Locally

Open two separate terminal windows to start the server and client concurrently:

# Terminal 1: Run Backend API Server
cd server
npm run dev

# Terminal 2: Run Frontend React App
cd client
npm run dev

Open http://localhost:5173 in your browser to access the portal locally.

4. Docker Container Deployment

The project is fully dockerized for DevOps deployment. If you have Docker installed, you can launch the client, server, and database stack using a single command from the project root folder:

docker-compose up --build
